# User Persistent Design Rules

## 1. No Subtitle Badges / Eyebrow Pills
- **NEVER** add Subtitle Badges, Eyebrow Pills, or pulsing pill tags (e.g. `[● Verified Courts...]`, `[● Smart Booking...]`, etc.) above or below section titles or hero headlines on any page or website.
- Start directly with the main headline (`<h1>` / `<h2>`) and its concise subtext without pill badges floating above it.

## 2. Button Styling
- Always use the user's signature `<Button>` component (`cyber-btn` / `cyber-btn-secondary` with polygon clip-path cuts and animated gradient borders).
